## 因子逻辑

### 核心思想

当股票产生突发性利好信息时，普通投资者由于信息劣势难以及时发觉，而信息优势投资者会在短时间内大量买入，导致成交量激增。如果成交量激增后，市场并未产生大量跟随，则意味着反应不足，这些股票后续可能存在一定的超额收益。

### 构建步骤

1. **数据预处理**
   - 取个股1分钟频率交易数据
   - 剔除每天9:45之前的数据（开盘前15分钟交易过于活跃）

2. **寻找"海量时刻"**
   - 找到当日成交量最大的10个分钟时刻
   - 统称为"海量时刻"

3. **筛选"优势时刻"**
   - 从时间上最靠前的"海量时刻"开始
   - 相邻两个"海量时刻"间隔>5分钟 → 保留（独立时刻）
   - 相邻两个"海量时刻"间隔<5分钟 → 剔除后者（跟随交易）
   - 剩余即为"优势时刻"

4. **计算"跟随系数"**
   - "优势时刻"之后的5分钟定义为"跟随时刻"
   - 跟随系数 = 跟随时刻成交量总和 ÷ 优势时刻成交量

5. **计算日跟随系数**
   - 日内所有"跟随系数"的均值

6. **合成月频因子**
   - 月均待著而救 = 过去20日跟随系数均值
   - 月稳待著而救 = 过去20日跟随系数标准差
   - **待著而救因子 = 月均 + 月稳（等权合成）**

## 因子方向

**负向因子**（因子值越小，未来收益越高）

- 跟随系数小 → 市场反应不足 → 后续有超额收益
- 跟随系数大 → 市场反应过度 → 后续回落风险
