## 因子逻辑

### 核心思想
博彩偏好型投资者偏好具有博彩性质的股票，高估那些有较低概率获得高收益的股票的价值。股价突然跳跃上涨的个股更容易吸引这类投资者（犹如火光吸引飞蛾），但往往由于被过分关注而被超买，导致未来股价下跌。

相反，真正基本面向好、股价能够持续上涨的股票，其上涨过程往往是**均匀平缓非跳跃**的。因此通过对股价变化过程的跳跃程度加以衡量，可以找出真正向好的股票。

### 学术支撑
Jiang(2008) 提出了一种衡量股价跳跃的方法，研报对其进行简化应用。

### 构建步骤

#### 1. 月跳跃度因子（基于分钟数据）
```
1) 单利收益率 = 收盘价/前一分钟收盘价 - 1
2) 连续复利收益率 = ln(收盘价/前一分钟收盘价)
3) 单复利差 = 单利收益率 - 连续复利收益率
4) 泰勒残项 = 2 × 单复利差 - 连续复利收益率²
5) 日跳跃度 = 日内泰勒残项均值
6) 月跳跃度 = (月均跳跃度 + 月稳跳跃度) / 2
```

**泰勒展开式原理**：
- 单利收益率 exp(x) - 1 可以泰勒展开为 x + x²/2 + ...
- 连续复利收益率 x 是展开式的第一项
- 泰勒残项捕捉了高阶项的信息，反映跳跃程度

#### 2. 振幅分类与修正
```
1) 振幅 = (最高价 - 最低价) / 前一日收盘价
2) 根据日跳跃度截面均值分类：
   - 日跳跃度 < 均值：太阳型振幅（振幅 × -1）
   - 日跳跃度 > 均值：火把型振幅（振幅 × 1）
3) 修正振幅 = 20日翻转振幅均值
```

**分类逻辑**：
- **火把型振幅**：股价发生明显跳跃，吸引博彩偏好投资者（飞蛾扑火）
- **太阳型振幅**：股价无跳跃，真正基本面向好（明亮但不会被追逐）

#### 3. 飞蛾扑火因子（最终合成）
```
飞蛾扑火因子 = (月跳跃度 + 修正振幅) / 2
```

## 经济学直觉

> "那些股价突然发生跳跃上涨的个股，会更容易吸引博彩偏好型投资者前来购买，犹如耀眼的火光更容易吸引飞蛾，然而这些突然跳跃上涨的个股，往往由于被过分关注而被超买，从而导致未来股价下跌。相反，那些真正基本面向好、股价能够持续上涨的股票，其上涨的过程往往是均匀平缓非跳跃的。"

——方正证券研报原文

### 核心洞察
传统振幅因子效果不稳定的原因：吸引博彩偏好投资者的并不是"波动"而是"跳跃"。波动率因子之所以有效，是因为波动大的个股包含"跳跃"的可能性更大一些。

因此，**识别出波动中的跳跃**是增强改进波动类因子的有效途径。
