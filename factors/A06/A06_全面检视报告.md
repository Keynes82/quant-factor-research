## 二、详细比对分析

### 2.1 泰勒残项计算（股价跳跃度）

**研报原文（第7-8页）**：
> 1) 单利收益率 = 收盘价/前一分钟收盘价 - 1  
> 2) 连续复利收益率 = ln(收盘价/前一分钟收盘价)  
> 3) 单复利差 = 单利收益率 - 连续复利收益率  
> 4) 泰勒残项 = 2 × 单复利差 - 连续复利收益率²

**代码实现**（第150-162行）：
```python
# 计算单利收益率
df['simple_return'] = df.groupby(['instrument', 'trade_date'])['close'].pct_change()

# 计算连续复利收益率
df['log_return'] = np.log(df['close'] / df.groupby(['instrument', 'trade_date'])['close'].shift(1))

# 计算单复利差
df['diff_return'] = df['simple_return'] - df['log_return']

# 计算泰勒残项 = 2 × 单复利差 - 连续复利收益率²
df['taylor_residual'] = 2 * df['diff_return'] - df['log_return'] ** 2
```

**逐项比对**：
| 步骤 | 研报公式 | 代码实现 | 结果 |
|:----:|:--------:|:--------:|:----:|
| 1 | 单利收益率 = P_t/P_{t-1} - 1 | `pct_change()` | ✅ |
| 2 | 连续复利 = ln(P_t/P_{t-1}) | `np.log(close/shift(1))` | ✅ |
| 3 | 单复利差 = 单利 - 连续复利 | `simple_return - log_return` | ✅ |
| 4 | 泰勒残项 = 2×差 - 连续² | `2*diff_return - log_return**2` | ✅ |

**评估**: ✅ **100% 一致**

### 2.3 振幅计算

**研报原文**：
> 振幅 = (最高价 - 最低价) / 前一日收盘价

**代码实现**（第183-193行）：
```python
def calculate_daily_amplitude(daily_df: pd.DataFrame, prev_close_df: pd.DataFrame) -> pd.DataFrame:
    df = daily_df.copy()
    df = df.sort_values(['instrument', 'date']).reset_index(drop=True)
    
    # 获取前一日收盘价
    df['prev_close'] = df.groupby('instrument')['daily_close'].shift(1)
    
    # 计算振幅
    df['amplitude'] = (df['daily_high'] - df['daily_low']) / df['prev_close']
    
    return df
```

**评估**: ✅ **100% 一致**，使用`shift(1)`正确获取前一日收盘价。

### 2.4 太阳型/火把型分类（✅ 已修正）

**研报原文（第9页）**：
> 我们将每日个股日跳跃度从小到大排序，将日跳跃度**大于截面均值**的个股振幅视为火把型振幅，将日跳跃度**小于截面均值**的个股振幅视为太阳型振幅。
> 1. 将**火把型**振幅乘以1；2. 将**太阳型**振幅乘以-1

**关键概念**: "截面均值"指的是**每个交易日，所有股票的日跳跃度的均值**（cross-sectional mean），而非单只股票的历史均值。

#### v1.0 BUG（已修复）

**错误实现**（v1.0）：
```python
# ❌ 错误：使用历史均值
group['jumpiness_mean_cross'] = group['daily_jumpiness'].expanding(min_periods=1).mean()
```

**问题分析**:
- 代码使用的是 `expanding(min_periods=1).mean()`，这是**时间序列上的扩展均值**（单只股票自己历史的均值）
- 研报要求的是**截面均值**（cross-sectional mean，每天所有股票的均值）

#### v1.1 修正（当前版本）

**正确实现**（v1.1）：
```python
# ✅ 正确：计算每日截面均值
daily_cross_mean = df.groupby('date')['daily_jumpiness'].mean().reset_index()
daily_cross_mean.columns = ['date', 'cross_mean_jumpiness']
df = df.merge(daily_cross_mean, on='date', how='left')

# 使用截面均值进行分类
group['flipped_amplitude'] = np.where(
    group['daily_jumpiness'] < group['cross_mean_jumpiness'],
    -group['amplitude'],  # 太阳型：翻转
    group['amplitude']     # 火把型：不变
)
```

**评估**: ✅ **100% 一致**（v1.1已修正）
