## 二、详细逐项比对

### 2.1 月跳跃度因子（100% 一致）

**研报原文**（第4-5页）：
> 1）剔除开盘和收盘，仅考虑日内数据。  
> 2）单利收益率 = t分钟收盘价/t-1分钟收盘价-1  
> 3）连续复利收益率 = ln(t分钟收盘价/t-1分钟收盘价)  
> 4）单复利差 = 单利收益率 - 连续复利收益率  
> 5）泰勒残项 = 2×单复利差 - 连续复利收益率²  
> 6）日跳跃度 = 日内泰勒残项均值  
> 7）月跳跃度 = (月均跳跃度 + 月稳跳跃度) / 2

**代码实现**（第148-172行）：
```python
# 步骤2：单利收益率
df['simple_return'] = df.groupby(['instrument', 'trade_date'])['close'].pct_change()

# 步骤3：连续复利收益率
df['log_return'] = np.log(df['close'] / df.groupby(['instrument', 'trade_date'])['close'].shift(1))

# 步骤4：单复利差
df['diff_return'] = df['simple_return'] - df['log_return']

# 步骤5：泰勒残项
df['taylor_residual'] = 2 * df['diff_return'] - df['log_return'] ** 2

# 步骤6：日跳跃度
daily_jumpiness = df.groupby(['instrument', 'trade_date']).agg({
    'taylor_residual': 'mean',
    ...
})

# 步骤7：月跳跃度（第219-226行）
group['monthly_jumpiness_mean'] = group['daily_jumpiness'].rolling(window=FACTOR_WINDOW, ...).mean()
group['monthly_jumpiness_std'] = group['daily_jumpiness'].rolling(window=FACTOR_WINDOW, ...).std()
group['monthly_jumpiness'] = (group['monthly_jumpiness_mean'] + group['monthly_jumpiness_std']) / 2
```

**评估**: ✅ **完全一致**

### 2.2 修正振幅因子1（100% 一致）

**研报原文**（第8页）：
> 1）振幅 = (t日最高价 - t日最低价) / (t-1日收盘价)  
> 2）每天计算"日跳跃度"的截面均值，日跳跃度 < 截面均值 → 太阳型（振幅×-1）；日跳跃度 > 截面均值 → 火把型（振幅×1）  
> 3）每月月底，计算过去20天的"翻转振幅"的均值

**代码实现**（第183-226行）：
```python
# 步骤1：振幅计算（第183-193行）
df['prev_close'] = df.groupby('instrument')['daily_close'].shift(1)
df['amplitude'] = (df['daily_high'] - df['daily_low']) / df['prev_close']

# 步骤2：截面均值计算 + 分类（第201-226行）
daily_cross_mean = df.groupby('date')['daily_jumpiness'].mean().reset_index()  # ✅ 截面均值
daily_cross_mean.columns = ['date', 'cross_mean_jumpiness']
df = df.merge(daily_cross_mean, on='date', how='left')

# 分类逻辑
group['flipped_amplitude'] = np.where(
    group['daily_jumpiness'] < group['cross_mean_jumpiness'],
    -group['amplitude'],  # 太阳型：翻转
    group['amplitude']    # 火把型：不变
)

# 步骤3：20日均值（第228-230行）
group['corrected_amplitude'] = group['flipped_amplitude'].rolling(
    window=FACTOR_WINDOW, min_periods=FACTOR_WINDOW
).mean()
```

**关键修正**（v1.1）：
- v1.0错误：使用`expanding(mean)`计算单只股票历史均值
- v1.1修正：使用`groupby(date).mean()`计算每日截面均值 ✅

**评估**: ✅ **完全一致**
