## 因子逻辑

### 核心思想
个股日内成交量的变化宛如"潮汐"：从低潮到高潮再到低潮。通过识别这一完整的"潮汐"过程，计算价格变动速率，捕捉投资者交易热情变化中的反应过度/反应不足。

### 构建步骤

```
┌─────────────────────────────────────────────────────────────┐
│  步骤1: 识别"潮汐"过程                                       │
│  ├─ 计算邻域成交量 = 每分钟及其前后4分钟成交量总和(共9分钟) │
│  ├─ 顶峰时刻(t)：邻域成交量最高点                           │
│  ├─ 涨潮时刻(m)：第5~t-1分钟里，邻域成交量最低点            │
│  └─ 退潮时刻(n)：第t+1~233分钟里，邻域成交量最低点          │
├─────────────────────────────────────────────────────────────┤
│  步骤2: 判断强势/弱势半潮汐                                 │
│  ├─ 若 Vm < Vn：涨潮为强势半潮汐，退潮为弱势半潮汐         │
│  └─ 若 Vm > Vn：退潮为强势半潮汐，涨潮为弱势半潮汐         │
├─────────────────────────────────────────────────────────────┤
│  步骤3: 计算价格变动速率                                    │
│  ├─ 全潮汐 = (Cn-Cm)/Cm/(n-m)                              │
│  ├─ 强势半潮汐 = 强势段价格变动 / 强势段分钟数             │
│  └─ 弱势半潮汐 = 弱势段价格变动 / 弱势段分钟数             │
├─────────────────────────────────────────────────────────────┤
│  步骤4: 合成完整潮汐因子                                    │
│  ├─ 强势半潮汐因子 = mean(强势半潮汐, 20日)                │
│  ├─ 稳定弱势半潮汐因子 = std(弱势半潮汐, 20日)             │
│  └─ 完整潮汐因子 = (强势半潮汐 + 稳定弱势半潮汐) / 2       │
└─────────────────────────────────────────────────────────────┘
```
