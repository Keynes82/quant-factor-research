## 因子逻辑

### 核心思想
显著理论（Salience Theory）认为，那些收益率**过分低于市场**的股票，会导致投资者产生**恐慌心理**并引起过度卖出，进而股价会在未来发生补涨。

> "我们将这种心理称为'草木皆兵'心理，投资者认为这种极端偏离市场的低收益（或称为严重亏损）会再次出现，因此纷纷卖出这些股票并远离它们。"

### 学术支撑
- Cosemans & Frehen (2021): 显著理论与因子构造
- Cakici & Zaremba (2021): 显著效应在波动率加剧时更加强烈
- Kahneman & Tversky: 前景理论 - 极端收益扭曲决策权重

### 构建步骤

#### 1. 惊恐度计算
```
偏离项 = |个股收益率 - 市场收益率|
基准项 = |个股收益率| + |市场收益率| + 0.1
惊恐度 = 偏离项 / 基准项
```

**参数说明**：基准项中加0.1是为了避免除以0的情况，同时保证当个股收益率为0时不会得到不合理的惊恐度。

#### 2. 波动率加剧（基于1分钟数据）
```
日波动率 = 日内每分钟收益率的标准差
```

根据Cakici & Zaremba (2021)的研究，显著效应在**波动率加剧时更加强烈**。

#### 3. 加权决策分
```
加权决策分 = 惊恐度 × 波动率 × 收益率
```

#### 4. 草木皆兵因子（低频化）
```
草木皆兵因子 = (20日加权决策分均值 + 20日加权决策分标准差) / 2
```

## 经济学直觉

### "守株待兔" vs "草木皆兵"

| 心理类型 | 收益偏离 | 投资者反应 | 未来走势 |
|----------|----------|------------|----------|
| **守株待兔** | 远高于市场 | 过度买入，等待高收益再现 | 回落 ⬇️ |
| **草木皆兵** | 远低于市场 | 恐慌卖出，远离亏损股票 | 补涨 ⬆️ |

### 核心洞察
当市场平静时（市场收益率≈0），个股的大跌会给投资者带来更多的恐慌情绪，导致这一天的投资者反应过度的程度更加强烈，即更加容易过度卖出。

例如：
- 情景A：市场收益0%，个股收益-5% → 惊恐度 = 0.05/0.15 = 0.33
- 情景B：市场收益-3%，个股收益-10% → 惊恐度 = 0.07/0.21 = 0.33

虽然都是跌5%（相对市场），但情景A的绝对偏离更大，惊恐度更高，未来补涨概率更大。
