## 因子逻辑

### 核心思想

成交量的放量和缩量都可能蕴含丰富的价格信息，只考虑"激增时刻"（放量）单边的信息可能会遗漏部分交易量突变的信息。本研报同时考察成交量"激增时刻"和"骤降时刻"的价格波动，研究投资者对这两种情形的反应强度是否对称。

如果投资者对激增和骤降反应强度差异大（非理性），则当天的收益率幅度可能被放大，后续存在修正空间。

### 构建步骤

#### 步骤1-3：识别"正态激增时刻"与"正态骤降时刻"

1. **数据准备**
   - 剔除开盘与收盘数据，仅考虑日内每分钟交易量
   - 剔除成交量为0的时刻，将余下时间排成新序列（"正量序列"）

2. **Box-Cox变换**
   - 对正量序列进行boxcox变换，使其成为正态分布
   - 计算变换后每一分钟相对前一时刻的交易量变化量

3. **识别关键时刻**
   - 计算当天成交量变化量的均值(mean)和标准差(std)
   - **正态激增时刻**：成交量变化量 > mean + std
   - **正态骤降时刻**：成交量变化量 < mean - std

#### 步骤4-6：计算两个细分因子并合成

4. **波动公平因子**
   - 将"正态激增时刻"的1分钟及其随后4分钟记为"**正态耀眼五分钟**"
   - 将"正态骤降时刻"的1分钟及其随后4分钟记为"**正态黯淡五分钟**"
   - 计算两种五分钟的波动率均值
   - 波动公平度 = |耀眼波动率 - 黯淡波动率|
   - 波动公平收益率 = 日内收益率 × 波动公平度

5. **收益公平因子**
   - 计算"正态激增时刻"与"正态骤降时刻"的收益率均值
   - 收益公平度 = |激增收益率均值 - 骤降收益率均值|
   - 收益公平收益率 = 日内收益率 × 收益公平度

6. **合成一视同仁因子**
   - **一视同仁 = 波动公平因子 + 收益公平因子（等权合成）**

## 因子方向

**负向因子**（因子值越小，未来收益越高）

- 公平度大 → 投资者对激增/骤降反应不对称 → 非理性程度高 → 未来收益修正（因子值小对应高收益）
- 公平度小 → 投资者对激增/骤降反应对称 → 理性程度高 → 未来收益正常
