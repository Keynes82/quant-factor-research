## 一、问题发现

在对比检视中发现，v1.0高性能版代码与研报原文存在**严重偏差**：

| 维度 | 研报原文 | v1.0代码 | 偏差 |
|:----:|----------|----------|:----:|
| **更优波动率** | (5分钟OHLC共20个价格的std/mean)² | 1分钟收盘价的滚动标准差 | 🔴严重 |
| **收益波动比** | 分钟收益率 / 更优波动率 | ❌未计算 | 🔴严重 |
| **核心指标** | 协方差 cov(收益波动比, 更优波动率) | 动态动量 × 波动率均值 | 🔴严重 |
| **异常识别** | 更优波动率 ≥ mean + std | 波动率变化率突增/骤降点 | 🟡中等 |

**结论**: v1.0代码实际构建的是一个"波动率动量"因子，与研报定义的"勇攀高峰"因子经济学含义完全不同。

## 六、技术细节

### 更优波动率计算示例
```python
# 第t分钟的更优波动率
# 使用t-4, t-3, t-2, t-1, t共5分钟的OHLC数据
prices = [
    open_t_4, high_t_4, low_t_4, close_t_4,  # t-4分钟
    open_t_3, high_t_3, low_t_3, close_t_3,  # t-3分钟
    open_t_2, high_t_2, low_t_2, close_t_2,  # t-2分钟
    open_t_1, high_t_1, low_t_1, close_t_1,  # t-1分钟
    open_t,   high_t,   low_t,   close_t     # t分钟
]  # 共20个价格

better_volatility = (np.std(prices) / np.mean(prices)) ** 2
```

### 异常高波动时段识别
```python
# 计算当日更优波动率的均值和标准差
vol_mean = day_better_vol.mean()
vol_std = day_better_vol.std()

# 识别异常高波动时段
high_vol_mask = better_volatility >= (vol_mean + vol_std)
```

### 勇攀高峰因子合成
```python
# 20日低频化
mean_cov = covariance_series.rolling(20).mean()
std_cov = covariance_series.rolling(20).std()
climbing_peak_factor = (mean_cov + std_cov) / 2
```
