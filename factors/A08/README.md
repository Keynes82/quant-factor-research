## 因子逻辑

### 核心思想
当股票波动非常大时，投资者的风险厌恶会快速增加。但对于波动异常高的时段，那些能**给异常高波动及时提供风险补偿**的股票，展现出了非凡的能力，这种向好的势头将会长期持续。

> "那些波动异常高的同时也伴随着超高的收益率的股票，虽然看起来风险加剧、股价位于高位，像是一座险峻巍峨的高山，让人望而却步。但事实上，在此情此景下只有敢于勇攀高峰的人，才能抓住这些真正利好的股票。"

### 学术支撑
- Moreira & Muir (2017): 收益波动比与波动率的关系
- Lochstoer & Muir (2022): 投资者对波动率的反应不足与反应过度

### 构建步骤

#### 1. 更优波动率计算（基于最近5分钟OHLC）
```
取第t-4、t-3、t-2、t-1、t分钟的OHLC数据（共20个价格）
更优波动率 = (标准差 / 均值)²
```

**改进目的**：尽量减少分钟内的信息丢失，防止上一分钟收盘到本次收盘内的波动被忽略。

#### 2. 收益波动比计算
```
收益波动比 = 分钟收益率 / 更优波动率
```

#### 3. 识别异常高波动时段
```
当日更优波动率均值 = mean，标准差 = std
异常高波动 = 更优波动率 >= mean + std
```

#### 4. 计算协方差（仅异常高波动时段）
```
协方差 = cov(收益波动比, 更优波动率)
```

在异常高波动时段，如果收益波动比随波动率提高而上升，表明异常波动得到了充足的风险补偿。

#### 5. 勇攀高峰因子（低频化）
```
勇攀高峰因子 = (20日协方差均值 + 20日协方差标准差) / 2
```

## 经济学直觉

### 波动率的两种含义
1. **风险加剧**：波动率增大预示风险增加
2. **股价飙升前兆**：波动率增大可能是股价飙升的信号

### 关键区分点
分辨波动率提升是喜是忧的关键在于：**波动率加剧的同时收益率有没有随之提高**。

### 勇攀高峰的逻辑
- 当波动异常高时，人们风险厌恶快速变大
- 能给异常高波动及时提供风险补偿的股票，展现了非凡的能力
- 投资者有理由相信，这种向好的势头将会长期持续
- 只有敢于"勇攀高峰"的人，才能抓住这些真正利好的股票
