### 🔴 发现1：s1/s2调整逻辑存在符号问题（潜在BUG）

**位置**: `calculate_clouds_clearing_factor_v2` 函数，第398-400行

**代码**:
```python
# 保持数量级一致：修正后的负值部分 = 修正后的负值部分 / s2 * s1
group.loc[negative_adjusted_mask, 'adjusted_spread'] = (
    group.loc[negative_adjusted_mask, 'adjusted_spread'] / s2 * s1
)
```

**问题分析**:
- `s1` 是原始负值的和（负数）
- `s2` 是修正后负值的和（负数，因为负值除以正数标准差后仍为负值）
- 因此 `s1/s2` 是 负数/负数 = 正数
- 但这里有个微妙问题：如果修正后某些股票从负变正（当原始值接近0时除以标准差可能变为正），`s2`的计算可能不准确

**更深层问题**:
```python
# 这行代码筛选的是修正后为负的值
negative_adjusted = group[group['adjusted_spread'] < 0]['adjusted_spread']
s2 = negative_adjusted.sum()

# 但下面的筛选条件可能包含修正后为正的值（如果原始为负，修正后变正，不会进入这个mask）
negative_adjusted_mask = group['adjusted_spread'] < 0
group.loc[negative_adjusted_mask, 'adjusted_spread'] = ...  # 只对负值调整
```

**实际影响**: 这个逻辑是正确的，因为只有修正后仍为负的值才会被s2/s1调整。

**状态**: ✅ 逻辑正确，但需验证极端情况

## 二、代码逻辑验证

### 2.1 s1/s2数量级保持逻辑验证

**场景模拟**:
假设某天有3只股票，原始日模糊价差为：
- 股票A: -10 (标准差=2，稳定)
- 股票B: -5  (标准差=10，不稳定)
- 股票C: +3  (正值，不修正)

**计算过程**:
1. s1 = (-10) + (-5) = -15
2. 修正后:
   - 股票A: -10/2 = -5
   - 股票B: -5/10 = -0.5
   - 股票C: +3 (不变)
3. s2 = (-5) + (-0.5) = -5.5
4. 数量级调整:
   - 股票A: -5 / (-5.5) * (-15) = 0.909 * (-15) = -13.64
   - 股票B: -0.5 / (-5.5) * (-15) = 0.091 * (-15) = -1.36

**验证**:
- 调整后负值之和 = (-13.64) + (-1.36) = -15 = s1 ✅
- 数量级保持一致 ✅
- 股票A（稳定）的绝对值被放大（-5→-13.64）✅
- 股票B（不稳定）的绝对值被缩小（-0.5→-1.36）✅

**结论**: s1/s2逻辑正确实现了研报意图
