## 因子逻辑

### 核心思想
投资者普遍是**波动率的模糊性**（Ambiguity）的厌恶者。当模糊性较大时，投资者会急于卖出股票，减少在风险资产上的配置。

通过分析模糊性较大时的成交金额与成交量的差异，可以识别出投资者急于卖出的股票，这类股票由于反应过度，**未来大概率会发生补涨**。

### 学术支撑
Kostopoulos et al. (2021) 提出使用**波动率的波动率**来刻画波动率的模糊性。

### 构建步骤

#### 1. 计算模糊性（波动率的波动率）
```
1) 计算每分钟收益率
2) 计算5分钟滚动波动率（收益率的标准差）
3) 计算5分钟滚动模糊性（波动率的标准差）
```

#### 2. 识别"起雾时刻"
```
起雾时刻 = 模糊性 > 当日模糊性均值 的时间段
```

#### 3. 计算日频因子
```
模糊金额比 = 雾中金额 / 总体金额
模糊数量比 = 雾中数量 / 总体数量
模糊价差   = 模糊金额比 - 模糊数量比
```

**经济学含义**：
- 当模糊性较大时，如果平均成交金额比例 **远小于** 平均成交量比例
- 说明投资者急于卖出，挂单价格明显偏低（付出的流动性成本）
- 此时容易发生反应过度，未来大概率会发生补涨

#### 4. 低频化（月频）
```
云开雾散因子 = (月均模糊价差 + 月稳模糊价差) / 2
```

### 三因子合成逻辑（研报第12页）

```
云开雾散因子 = (模糊关联度因子 + 模糊金额比因子 + 修正模糊价差因子) / 3

其中每个子因子 = (月均 + 月稳) / 2
    月均 = 过去20日均值
    月稳 = 过去20日标准差
```
