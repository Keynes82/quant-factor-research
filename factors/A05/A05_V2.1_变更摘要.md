根据研报第11页，修正模糊价差的完整计算步骤如下：

| 步骤 | 研报原文 | 代码实现 |
|:----:|----------|----------|
| 1 | 计算日模糊价差 = 模糊金额比 - 模糊数量比 | ✅ v2.0已实现（保留） |

| 3 | 计算截面上日模糊价差负值部分的和s1 | ✅ v2.1新增 `s1 = negative_spread.sum()` |

| 5 | 计算截面上修正后负值部分的和s2 | ✅ v2.1新增 `s2 = negative_adjusted.sum()` |
| 6 | 负值部分除以s2乘以s1，保持数量级 | ✅ v2.1新增 `adjusted / s2 * s1` |
| 7 | 均修正模糊价差 + 稳模糊价差等权合成 | ✅ v2.1修正（注意：稳模糊价差使用原始标准差） |

#### 变更后（v2.1）
```python
# ========== 第一步：计算修正日模糊价差（研报第11页）==========
# 1. 计算过去10天的滚动标准差（用于修正）
df['ambiguity_spread_std_10d'] = df.groupby('instrument')['ambiguity_spread'].rolling(
    window=10, min_periods=5
).std().reset_index(level=0, drop=True)

# 2. 截面修正逻辑（按日期分组处理）
def adjust_ambiguity_spread_cross_section(group):
    # s1: 截面上原始日模糊价差为负的部分的和
    negative_spread = group[group['ambiguity_spread'] < 0]['ambiguity_spread']
    s1 = negative_spread.sum() if len(negative_spread) > 0 else 1e-10
    
    # 修正：负值部分除以过去10天标准差，正值部分不变
    group['adjusted_spread'] = group['ambiguity_spread']
    negative_mask = group['ambiguity_spread'] < 0
    std_10d = group['ambiguity_spread_std_10d']
    valid_std = negative_mask & std_10d.notna() & (std_10d > 1e-10)
    group.loc[valid_std, 'adjusted_spread'] = group.loc[valid_std, 'ambiguity_spread'] / std_10d[valid_std]
    
    # s2: 截面上修正后负值部分的和
    negative_adjusted = group[group['adjusted_spread'] < 0]['adjusted_spread']
    s2 = negative_adjusted.sum() if len(negative_adjusted) > 0 else 1e-10
    
    # 保持数量级一致
    negative_adjusted_mask = group['adjusted_spread'] < 0
    group.loc[negative_adjusted_mask, 'adjusted_spread'] = (
        group.loc[negative_adjusted_mask, 'adjusted_spread'] / s2 * s1
    )
    
    return group

# 按日期分组，进行截面修正
df = df.groupby('date', group_keys=False).apply(adjust_ambiguity_spread_cross_section)

# ========== 第二步：子因子3合成（研报第11页）==========
# 均修正模糊价差 = 过去20日修正日模糊价差的均值
group['adjusted_spread_mean'] = group['adjusted_spread'].rolling(
    window=FACTOR_WINDOW, min_periods=FACTOR_WINDOW
).mean()

# 稳模糊价差 = 过去20日原始日模糊价差的标准差（注意：不是修正后的！）
group['original_spread_std'] = group['ambiguity_spread'].rolling(
    window=FACTOR_WINDOW, min_periods=FACTOR_WINDOW
).std()

# 修正模糊价差 = (均修正模糊价差 + 稳模糊价差) / 2
group['ambiguity_spread_factor'] = (group['adjusted_spread_mean'] + group['original_spread_std']) / 2
```

## 三、技术细节

### 3.1 截面修正逻辑

**为什么要做截面修正？**

研报第11页解释：
> "我们对多头的逻辑进一步拆分...当个股日模糊价差为负，且绝对值较大时，如果其每天的模糊价差大小不定，则此情形更像是偶尔出现重大利空事件导致的；如果其每天的模糊价差大小稳定，则大概率没有发生基本面恶化，此情形更像是投资者持续性反应过度导致的。"

**修正逻辑的本质**：
1. 用过去10天标准差作为"稳定性"的度量
2. 对"不稳定"的负值（标准差大）进行"惩罚"（除以较大的标准差，绝对值变小）
3. 对"稳定"的负值（标准差小）进行"奖励"（除以较小的标准差，绝对值变大）
4. s1/s2调整是为了保持修正后的数量级与原始数量级一致，避免行业市值中性化时受影响

### 3.2 稳模糊价差的数据来源

**重要细节**：根据研报第11页，稳模糊价差使用的是**原始日模糊价差**的20日标准差，而不是修正后的日模糊价差的标准差。

```python
# 正确的实现
group['original_spread_std'] = group['ambiguity_spread'].rolling(...).std()  # 原始值

# 错误的实现（不要用修正后的）
group['adjusted_spread_std'] = group['adjusted_spread'].rolling(...).std()   # 修正值 ❌
```

### 3.3 边界条件处理

| 边界条件 | 处理方式 |
|----------|----------|
| s1 = 0（无负值） | 设为1e-10避免除零 |
| s2 = 0（修正后无负值） | 设为1e-10避免除零 |
| std_10d = NaN | 跳过修正，保留原始值 |
| std_10d = 0 | 跳过修正（避免除以零） |
| 数据不足10天 | min_periods=5，至少5天 |
