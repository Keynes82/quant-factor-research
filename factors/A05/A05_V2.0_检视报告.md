## 三、前视偏差（Look-ahead Bias）检查

### 3.1 因子计算逻辑

**当日计算因子值用于次日操作，是否存在前视偏差？**

| 计算步骤 | 使用数据 | 是否存在前视偏差 |
|----------|----------|------------------|
| 分钟收益率 | 当日分钟close | ❌ 无（当前分钟 vs 上一分钟） |
| 5分钟滚动波动率 | t-4到t分钟 | ⚠️ **有！使用未来4分钟数据** |
| 5分钟滚动模糊性 | t-4到t分钟波动率 | ⚠️ **有！使用未来4分钟数据** |
| 日模糊关联度 | 当日所有分钟 | ❌ 无（收盘后计算） |
| 日模糊金额比 | 当日所有分钟 | ❌ 无（收盘后计算） |
| 月均/月稳 | 过去20个交易日 | ❌ 无（滚动窗口） |

### 3.2 关键问题：模糊性计算的前视偏差

**问题描述**：

代码中使用的是**中心滚动窗口**计算波动率和模糊性：
```python
# 计算5分钟滚动波动率（前5分钟收益率的标准差）
df['volatility'] = df.groupby(['instrument', 'trade_date'])['minute_return'].rolling(
    window=VOL_WINDOW, min_periods=VOL_WINDOW
).std().reset_index(level=[0, 1], drop=True)
```

这里的注释写的是"前5分钟"，但实际代码使用的是`rolling(window=5)`，这在pandas中默认是**包含当前时刻的前5个值**（即t-4, t-3, t-2, t-1, t）。

**研报原文要求（第4页）**：
> 3) 对于第t分钟，计算第t-4、t-3、t-2、t-1、t分钟的收益率的标准差，作为第t分钟的波动率

**问题分析**：
- 如果在盘中实时计算，第t分钟的模糊性需要用到t+1到t+4分钟的数据（如果是中心对齐）
- 但pandas的rolling默认是右对齐（包含当前时刻），所以实际上是用了t-4到t的数据
- **对于收盘后的日频因子计算，这不是问题**，因为所有分钟数据都已知
- **对于盘中实时计算，这会引入前视偏差**

### 3.3 结论

| 场景 | 是否存在前视偏差 | 说明 |
|------|------------------|------|
| 收盘后计算日频因子 | ❌ 无 | 所有分钟数据已确定 |
| 盘中实时计算 | ⚠️ 有 | 需要等待未来4分钟数据 |
| 用于次日交易 | ❌ 无 | 只要昨日收盘后计算完成 |

**建议**：如果需要在盘中实时预警，应该修改计算方式为**纯滞后窗口**（只用t-5到t-1的数据）。
