## 因子逻辑

### 核心思想
在股票市场中，成交量的边际变化隐含重要信息。通过观察日内成交量激增时段的价格波动和收益率，构建衡量投资者"适度冒险"程度的因子。

### 构建步骤

```
┌─────────────────────────────────────────────────────────────┐
│  步骤1: 识别成交量激增时刻                                    │
│  ├─ 计算成交量增加量 = volume(t) - volume(t-1)               │
│  ├─ 计算当日均值(mean)和标准差(std)                          │
│  └─ 激增时刻 = volume_diff > mean + std                      │
├─────────────────────────────────────────────────────────────┤
│  步骤2: 计算日耀眼波动率                                      │
│  ├─ 耀眼5分钟 = 激增时刻及其随后4分钟                        │
│  └─ 日耀眼波动率 = mean(std(returns in 耀眼5分钟))           │
├─────────────────────────────────────────────────────────────┤
│  步骤3: 计算日耀眼收益率                                      │
│  └─ 日耀眼收益率 = mean(returns at 激增时刻)                 │
├─────────────────────────────────────────────────────────────┤
│  步骤4: 构建适度指标                                          │
│  ├─ 适度波动 = |日耀眼波动 - 截面均值|                       │
│  └─ 适度收益 = |日耀眼收益 - 截面均值|                       │
├─────────────────────────────────────────────────────────────┤
│  步骤5: 20日滚动合成                                          │
│  ├─ 月耀眼波动 = (mean(适度波动,20) + std(适度波动,20)) / 2  │
│  ├─ 月耀眼收益 = (mean(适度收益,20) + std(适度收益,20)) / 2  │
│  └─ 适度冒险因子 = (月耀眼波动 + 月耀眼收益) / 2             │
└─────────────────────────────────────────────────────────────┘
```
