## 因子逻辑

### 核心思想
水中行舟因子由两个逻辑不同、方向相反、相关性接近0的子因子等权合成：

> "顺水行舟，事半功倍；逆水行舟，事倍功半。"

### 子因子一：随波逐流（正向因子）

**场景**：当个股股价处于相对高位时

**逻辑**：
- 成交额与市场趋势关联性**越高越好**
- 如果成交额更多由市场趋势带动（而非个股独立交易），表明投资者看法一致，上涨趋势可能还未结束
- 如果有很多与市场趋势无关的独立交易，表明投资者存在较大分歧，上涨趋势或将结束

**构建步骤**：
1. 合理收益率 = 过去20日日内收益率（收盘/开盘-1）的均值
2. 分钟相对开盘收益率 = 分钟收盘价 / 当日开盘 - 1
3. 高位成交额 = 相对开盘收益率 > 合理收益率 的分钟成交额之和
4. 低位成交额 = 相对开盘收益率 < 合理收益率 的分钟成交额之和
5. 高低额差 = (高位成交额 - 低位成交额) / 流通市值
6. 随波逐流 = 每只股票与其他股票"高低额差"序列的**spearman相关系数**绝对值的均值

### 子因子二：孤雁出群（负向因子）

**场景**：当市场分化不明显时

**逻辑**：
- 成交额与市场趋势关联性**越低越好**
- 市场清淡缺乏热点时，成交额独立的股票更可能在酝酿新的热点

**构建步骤**：
1. 分钟市场分化度 = 每分钟所有股票分钟收益率的标准差
2. 不分化时刻 = 分钟市场分化度 < 当日均值 的时刻
3. 日孤雁出群 = 每只股票在"不分化时刻"成交额与其他股票的**pearson相关系数**绝对值的均值
4. 孤雁出群 = (20日均值 + 20日标准差) / 2

### 最终合成
```
水中行舟因子 = (随波逐流因子 + 孤雁出群因子) / 2
```

### v3.1实现要点

1. **随波逐流计算**（修正）：
   - 计算每日高低额差（高位成交额-低位成交额）/流通市值
   - **关键修正**：使用过去20个交易日的高低额差时间序列

   - 取均值得到随波逐流因子

2. **孤雁出群计算**（修正）：
   - 计算分钟市场分化度（所有股票收益率标准差）
   - 识别不分化时刻（分化度<均值）
   - **关键修正**：使用当日"不分化时刻"的分钟成交额时间序列
   - 计算每只股票与其他股票分钟序列的pearson相关系数绝对值
   - (20日均值 + 20日标准差) / 2

3. **合成**：等权相加 (随波逐流 + 孤雁出群) / 2

### v3.2 高性能并行版（新增）

**推荐场景**：全市场5000+只股票的大规模计算

| 特性 | v3.1（串行） | v3.2（并行） |

| **计算方式** | 串行双重循环 O(n²) | 8核并行，按日期分治 |

| **性能提升** | 基准（单核） | **预期 5-8倍加速** |

**并行优化策略**：

2. **多进程架构**：`ProcessPoolExecutor(max_workers=8)`
3. **数据序列化**：`DataFrame.to_dict()` 实现进程间传递
4. **进度监控**：实时打印计算进度

**性能预估**（5000只股票×20日窗口）：

## 经济学直觉

### 两种市场情景

| 情景 | 市场状态 | 最优策略 | 子因子 |
|------|----------|----------|--------|
| **股价高位** | 趋势确立 | 随波逐流，跟随市场 | 随波逐流（正向） |
| **市场清淡** | 无热点 | 孤雁出群，寻找独立 | 孤雁出群（负向） |

### 核心洞察
- **随波逐流**：价格高位时，成交额跟随市场趋势 = 投资者看法一致 = 趋势延续
- **孤雁出群**：市场清淡时，成交额独立于市场 = 可能酝酿新热点 = 提前布局
