## 因子逻辑

### 核心思想

个股日内成交量的波动往往呈现一定的**周期性规律**。通过FFT（快速傅里叶变换）频谱分析，可以提取成交量的周期性特征。成交量波动呈现明显周期性规律的股票，往往具有更稳定的交易模式和更好的未来表现。

### 构建步骤

1. **数据准备**
   - 获取日内分钟级成交量数据
   - 要求至少30分钟有效数据

2. **FFT频谱分析**
   - 对成交量序列进行中心化（去除均值）
   - 使用numpy.fft.fft进行快速傅里叶变换
   - 计算频谱能量（|FFT|^2）
   - 只保留正频率部分

3. **频谱特征提取**
   - **主频率**：能量最大的频率成分
   - **主频率能量占比**：主频率能量 / 总能量
   - **能量集中度**：前3大频率能量 / 总能量
   - **频谱熵**：衡量能量分布均匀程度

4. **日频因子计算**
   - 滴水穿石因子 = 主频率能量占比 × 能量集中度
   - 反映成交量周期性规律的强弱

5. **月频因子计算**
   - 过去20个交易日日因子的均值

### FFT特征说明

```python
# 计算FFT频谱特征
fft_features = {
    'dominant_freq': 主频率值,           # 能量最大的频率
    'dominant_energy_ratio': 主频率能量占比,  # 主频率能量 / 总能量
    'energy_concentration': 能量集中度,   # 前3大频率能量 / 总能量
    'spectral_entropy': 频谱熵           # 能量分布均匀程度
}

# 日频因子 = 主频率能量占比 × 能量集中度
factor = dominant_energy_ratio * energy_concentration
```

## 因子方向

**正向因子**（因子值越大，未来收益越高）

- 因子值大 → 成交量周期性规律明显 → 交易模式稳定 → 未来表现较好
- 因子值小 → 成交量周期性规律弱 → 交易模式不稳定 → 未来表现较差
