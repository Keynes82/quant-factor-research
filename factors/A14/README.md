## 因子逻辑

### 核心思想

个股价格的变动是由多种因素共同推动的。本因子将日内价格变化分解为**成交量驱动部分**和**非成交量驱动部分**，通过线性回归方法识别价格变化中由信息驱动（非成交量驱动）的成分占比。

非成交量驱动的价格变化占比越高，说明该股票的价格波动更多由新信息驱动，而非单纯的交易行为推动，这类股票往往具有更好的未来表现。

### 构建步骤

1. **数据准备**
   - 获取日内分钟级价格和成交量数据
   - 计算每分钟价格变化（close.diff()）
   - 标准化成交量

2. **价格-成交量分解**
   - 使用线性回归：价格变化 ~ 成交量
   - 回归预测值 = 成交量驱动部分
   - 残差 = 非成交量驱动部分

3. **计算非成交量驱动占比**
   - 非成交量驱动占比 = |残差|之和 / |价格变化|之和
   - 花隐林间因子 = 非成交量驱动占比

4. **月频因子计算**
   - 过去20个交易日日因子的均值

### 因子计算逻辑

```python
# 线性回归：价格变化 ~ 成交量
slope, intercept, r_value, p_value, std_err = stats.linregress(volumes, price_changes)

# 预测值（成交量驱动）
volume_driven = slope * volumes + intercept

# 残差（非成交量驱动）
non_volume_driven = price_changes - volume_driven

# 非成交量驱动占比（花隐林间因子）
non_volume_ratio = sum(|non_volume_driven|) / sum(|price_changes|)
```

## 因子方向

**负向因子**（因子值越小，未来收益越高）

- 因子值小 → 非成交量驱动占比低 → 价格变化更多由交易推动 → 未来表现较差（但研报显示负IC，说明相反？需要验证）
- 因子值大 → 非成交量驱动占比高 → 价格变化更多由信息驱动 → 未来表现较好

**注意**：研报Rank IC为-6.92%，表示因子值与收益负相关，即因子值越大收益越低，需要进一步验证因子定义方向。
