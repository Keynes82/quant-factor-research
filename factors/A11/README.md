## 因子逻辑

### 核心思想

在股票交易过程中，成交量的放大往往更容易吸引投资者关注，同时也更容易引发价格大幅波动。对于**放量下跌**情形，多空双方博弈激烈，在此过程中那些**买入力量更强**的股票，更能获得资金的认可，其后续表现可能相对较好。

### 构建步骤

1. **计算邻域成交量**
   - 每分钟"邻域成交量" = 当前分钟成交量 + 前4分钟成交量总和（5分钟窗口）

2. **划分放量/缩量状态**
   - 邻域成交量较前一时刻增加 → **放量**
   - 邻域成交量较前一时刻减少 → **缩量**

3. **划分上涨/下跌状态**
   - 过去5分钟价格趋势为正（当前close > 5分钟前close）→ **上涨**
   - 过去5分钟价格趋势为负 → **下跌**

4. **综合状态分类**
   - 放量上涨 (increase_up)
   - **放量下跌 (increase_down)** ← 重点关注
   - 缩量上涨 (decrease_up)
   - 缩量下跌 (decrease_down)

5. **计算日激流勇进因子**
   - 只关注**放量下跌**时刻
   - 买入强度 = 放量下跌期间成交金额比例 - 放量下跌期间成交量比例
   - 公式：`buy_intensity = amount_ratio - volume_ratio`

6. **计算月频因子**
   - 过去20个交易日日因子的均值

## 因子方向

**正向因子**（因子值越大，未来收益越高）

- 买入强度大 → 放量下跌时有资金逆势买入 → 后续表现较好
- 买入强度小 → 放量下跌时缺乏支撑 → 后续表现较差
