## 因子逻辑

### 核心思想
从行为金融学角度，当多空双方投资者之间的分歧程度较大时，无论短期内是多方占优还是空方主导，由于博弈程度较为激烈，股票都更有可能出现过度反应。

### 构建步骤

#### 1. 成交量博弈-收益率因子
```
1) 剔除开盘前5分钟及收盘前3分钟数据
2) 将每分钟成交量按照过去5分钟收益率从小到大排序 → 正序成交量之和
3) 将每分钟成交量按照过去5分钟收益率从大到小排序 → 倒序成交量之和
4) 日频因子 = 正序成交量 - 倒序成交量
5) 月均 + 月稳 → 合成"成交量博弈-收益率"因子
```

#### 2. 振幅博弈因子
```
1) 计算每分钟振幅 = (最高价 - 最低价) / 收盘价
2) 类似成交量博弈的计算方法，按收益率排序
3) 日频因子 = 正序振幅 - 倒序振幅
4) 月均 + 月稳 → 合成"振幅博弈"因子
```

#### 3. 多空博弈因子（最终合成）
```
多空博弈因子 = (成交量博弈 + 振幅博弈) / 2
```

### 均值距离化处理
研报中提到对日频因子进行"均值距离化"处理：
- 截面标准化（z-score）
- 减去均值并取绝对值

目的：多空博弈的激烈程度过高或过低都不利于未来超额收益，适中最好。
