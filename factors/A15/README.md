## 因子逻辑

### 核心思想

个股日内成交量的分布特征反映了其流动性结构。成交量分布越集中（少数时刻集中交易），说明该股票的流动性弹性越大——即在特定时刻容易出现流动性冲击。

本因子通过衡量日内成交量分布的集中度，刻画个股的流动性弹性特征。

### 构建步骤

1. **数据准备**
   - 获取日内分钟级成交量数据
   - 去除零值和NaN

2. **计算集中度指标**
   - **基尼系数**：衡量成交量分布的不均衡程度
     - 0：完全均衡（所有时刻成交量相等）
     - 1：完全不均衡（所有成交量集中在一个时刻）
   - **赫芬达尔指数（HHI）**：另一种集中度指标
   - **最大成交量占比**：最大单分钟成交量 / 总成交量
   - **前10%时间段成交量占比**：前10%高峰时刻成交量 / 总成交量

3. **日频因子计算**
   - 流动性弹性因子 = 基尼系数
   - 基尼系数越大，成交量分布越集中，流动性弹性越大

4. **月频因子计算**
   - 过去20个交易日日因子的均值

## 因子方向

**负向因子**（因子值越小，未来收益越高）

- 因子值大 → 成交量分布集中 → 流动性弹性大 → 易受冲击 → 未来收益较差
- 因子值小 → 成交量分布分散 → 流动性弹性小 → 交易稳定 → 未来收益较好
