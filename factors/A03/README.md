## 因子逻辑

### 核心理论
借鉴Moskowitz(2021)的"球队-硬币"理论：
- **抛硬币**：人们了解其规律 → 预期**反转**
- **猜球队**：人们不了解其规律 → 预期**动量**

### 应用到股票
| 股票类型 | 特征 | 投资者预期 | 实际可能发生 |
|----------|------|------------|--------------|
| **硬币型** | 可知性高（波动率低、换手稳定） | 预期反转 | 实际**动量** |
| **球队型** | 可知性低（波动率高、换手变化大） | 预期动量 | 实际**反转** |

### 构建步骤

```
球队硬币因子 = (修正日间反转 + 修正日内反转 + 修正隔夜反转) / 3

其中每个修正反转因子 = (波动翻转因子 + 换手翻转因子) / 2
```

**波动翻转逻辑**：
- 波动率 < 市场均值（硬币型）→ 收益率 × (-1)（预期动量）
- 波动率 > 市场均值（球队型）→ 收益率不变（预期反转）

**换手翻转逻辑**：
- 换手率变化量 < 市场均值（硬币型）→ 收益率 × (-1)（预期动量）
- 换手率变化量 > 市场均值（球队型）→ 收益率不变（预期反转）
